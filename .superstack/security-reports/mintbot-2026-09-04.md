# Security remediation verification — mintbot — 2026-09-04

## Outcome and scope

Implemented fixes for the seven issues identified in the whole-code review. Six issues are corrected; the Ink fee issue now has a fail-closed, buffered pre-signing check, with the unavoidable inclusion-time fee limitation documented. Also updated the withdrawn `chacha20` 0.10.1 dependency to compatible patch 0.10.2. Changes remain local and uncommitted.

This is a remediation verification report, not a certification that no vulnerabilities exist. The CSO skill's active-verification and residual-risk guidance informed the checks. No telemetry, unrelated machine audit, live mint, funded-wallet signing, or production API-key use was performed. The real `.env` contents were not read.

## Remediation map

| Review issue | Change | Evidence / status |
| --- | --- | --- |
| P1: Ink L1/operator fees omitted from gas budget | Query the canonical oracle for L1 upper-bound and operator fees, double their sum as a reserve, add it to execution fees, and recheck live balance before initial and replacement signing. Missing/malformed oracle data and overflow reject signing. | Mock-RPC component and replacement-budget tests pass. Mitigated, not an on-chain total-fee guarantee. |
| P1: Normal OpenSea estimates an empty placeholder | Defer estimation when no fixed limit is configured; hydrate and estimate the real SeaDrop call at activation. Signing policy explicitly refuses zero/deferred gas limits. | Regression proves no placeholder estimation RPC occurs and signing is refused. Fixed. |
| P2: Secret scanner excludes `.env` and entire benchmark source | Remove both path exceptions. Keep only generated build and Git-object exclusions. | Synthetic-fixture test detects `.env` and both probe keys in benchmark source. Actual Git-history and source scans pass. Fixed. |
| P2: Event confirmations are one block late | Count inclusion as confirmation 1 and require mined event metadata. Recheck canonicality on immediate event and backfill activation paths too. | Tests cover 0, 1, 2, and 5 confirmations, missing metadata, and removed events. Fixed. |
| P2: Parent `.env` bypasses local permission check | Load only the exact working-directory `.env`; reject malformed files without echoing contents. | Subprocess tests prove parent file is not loaded and insecure/malformed local files fail safely. Fixed. |
| P2: Silent client stalls manual trigger server | Bound each client read to 250 ms and stop the listener when the receiver closes. | A silent connection followed by an authenticated trigger succeeds within the test deadline. Fixed for a single stalled connection; sustained local flooding is not prevented. |
| P3: Local clock controls OpenSea stage decisions | Use startup RPC/latest block and incoming header timestamps for stage selection, expiry, advancement, and retries. Background refresh no longer drops stages based on wall time. | Stage-expiry and retry boundary tests pass; no wall-clock decisions remain in the bot scheduler. Fixed. |

## Remaining limitations and follow-up

1. **Ink fee variability:** L1 and operator fees can change after signing. The reserve is a conservative pre-broadcast check, not an enforceable on-chain total-fee ceiling. Only Ink's surcharge model is implemented; custom chains need their own estimator. Current oracle availability was tested with local mocks, not a live Ink transaction. See [OP Stack fee documentation](https://docs.optimism.io/op-stack/transactions/fees).
2. **Upstream maintenance:** `derivative` 2.2.0 and `paste` 1.0.15 remain in the dependency lockfile. These are maintenance advisories, not confirmed exploitable bugs in this project. Track upstream replacements; do not silently suppress the warnings. See [RUSTSEC-2024-0388](https://rustsec.org/advisories/RUSTSEC-2024-0388) and [RUSTSEC-2024-0436](https://rustsec.org/advisories/RUSTSEC-2024-0436).
3. **Dependency patch:** `chacha20` 0.10.2 fixes use of an SSE4.1 intrinsic in the SSE2 backend; only its version/checksum changed in Cargo.lock. See the [upstream changelog](https://github.com/RustCrypto/stream-ciphers/blob/master/chacha20/CHANGELOG.md).
4. **Production verification:** No live mint was submitted. Real collection eligibility, remote API behavior, proxy state, and inclusion-time conditions still require operator verification. Use normal mode and a dedicated low-balance wallet.
